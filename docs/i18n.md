# Translation

Zenith's interface speaks 35 languages: English and 34 translations. A developer
writes English and wraps it where it is displayed; the English string is the key.

```qml
text: I18n.tr("Power limit")
text: I18n.tr("Ready in %1 minutes").arg(n)
```

A string with no translation returns itself, so a gap shows English, never a
blank. Keep a sentence whole and use `%1`..`%9` for values, so a translation can
reorder them; a translation that loses or adds a placeholder fails the test.

## Where it lives

| Path | What |
|---|---|
| `shell/i18n/data/langs.json` | the language table: code, names, direction, locale |
| `shell/i18n/data/<code>.json` | one catalog per language; `en.json` is the key list |
| `shell/i18n/overrides/` | human fixes, already folded into the catalogs |
| `/usr/share/zenith/i18n` | `data/` as installed, read-only (`release/build.d/W16.build`) |
| `~/.local/share/zenith/i18n/<code>.json` | optional per-user fixes that win over the shipped file |
| `shell/Ui/Singletons/I18n.qml` | the one reader |

The package ships 12 MB of JSON (1.8 MB compressed): every language, because the
Hub's picker lists all of them and a listed language that does nothing is worse
than a shorter list. The user layer is under `~/.local/share`, not
`~/.config/zenith`, because `zenith materialize` mirrors all of
`/usr/share/zenith` into the latter and a stale mirror there would win.

## Choosing a language

`shell.json` `"language"`, written by the Hub's Global page through the daemon.
`auto` follows `Qt.locale()` (`LANG`/`LC_*`), a regional locale falling back to
its base language. `I18n.qml` watches the file, so every open surface
retranslates at once. Arabic, Hebrew and Persian set `I18n.rtl`; a top-level
surface mirrors itself with `LayoutMirroring.enabled: I18n.rtl`.

`ZENITH_I18N_DIR=$PWD/shell/i18n/data` points a development shell at the
checkout's catalogs.

## Adding a string or a language

A new string needs nothing to run; it shows in English until its entry is added
to `en.json` and each catalog. A new language is a row in `langs.json` plus its
`<code>.json`.

The catalogs are Ryoku's machine translations (GPL-3.0), rebranded, kept to the
strings Zenith's QML and Hub use plus those of Ryoku's apps that are not ported
yet. Ryoku's extractor and translator, its Go and shell runtimes and the
installer strings are not here: nothing in Zenith calls them.

`go test ./internal/i18n` (from `desktop/`) checks the catalogs are valid, match
`en.json` and keep their placeholders, and that nearly every `I18n.tr` string in
`shell/` has an entry.
